# Stoyan

Job-Matching-Plattform für Arbeitnehmer und Arbeitgeber.

## Geplante Funktionen
- Registrierung und Login
- Arbeitnehmerprofile
- Arbeitgeberprofile
- Stellenangebote
- Kandidatensuche
- Matching-System mit Match-Prozent
- Bewerbungen und Kontaktanfragen
- Datenschutz und rollenbasierte Zugriffe

## Technologie
Next.js · TypeScript · Tailwind CSS · Supabase · Vercel
